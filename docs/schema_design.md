# スキーマ設計メモ

## raw層

CSVをBigQueryにロードするための受け皿。

raw層では、欠損・表記ゆれ・文字列混在をそのまま保持する。
そのため、基本的に全カラムをSTRINGとして定義する。

## staging層

raw層から以下の変換を行う。

- 取引価格をINT64化
- 面積をFLOAT64化
- ㎡単価を計算
- 建築年から築年数を計算
- 取引時期から年・四半期を抽出
- 駅距離を数値化
- 駅距離帯を作成
- 築年帯を作成

## mart層

Looker Studioから参照する集計テーブル。

集計粒度は以下。

- 市区町村
- 取引年
- 取引四半期
- 駅距離帯
- 築年帯

主要KPIは以下。

- 取引件数
- 平均㎡単価
- 中央値㎡単価
- 前年同期比成長率
